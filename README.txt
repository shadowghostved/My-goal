MY GOAL — PWA PACKAGE

Files:
- index.html: the My Goal app
- manifest.webmanifest: install/app metadata
- service-worker.js: offline app-shell caching
- icons/: Android/PWA icons

NEXT:
1. Upload the contents of this folder to a public HTTPS host (GitHub Pages is a free option).
2. Open the published HTTPS address in PWABuilder.
3. Choose Android package and follow its signing/build steps.
4. Install the generated APK on your Android device.

IMPORTANT:
- The app stores goals in this browser/device using localStorage.
- Use Settings → Export backup before changing browsers, clearing site data, or moving devices.
- Test adding/editing/completing a goal after publishing.
